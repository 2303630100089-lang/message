# UI/UX Design System

## Visual Style
- Glassmorphism panels with blur and soft gradients.
- AMOLED black surfaces with high-contrast accents.
- Material You dynamic theming and adaptive typography.

## Core Screens
- Onboarding and auth flow
- Home feed + explore
- Chat list + chat view
- Community/server view
- Profile and settings
- Notifications and activity center

## Motion
- 120 FPS navigation transitions
- Micro-interactions: ripple + haptic
- Skeleton loaders and shimmer effects

## Accessibility
- Dynamic font scaling
- High-contrast mode
- Large touch targets

## Adaptive Icon & Branding
- Icon: pulsating sphere with dual-layer glow.
- Colors: midnight black (#050508), neon cyan (#38F6FF), violet (#8B5CF6).
