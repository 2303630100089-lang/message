# message

## Product requirement baseline

This repository now tracks a **comprehensive messaging-platform requirement** that includes:

- Core messaging (personal chats, groups, channels, communities)
- Identity and security (signup/login, OTP, 2FA, passkeys, biometric unlock)
- Rich communication (text, media, voice/video calls, live features)
- Moderation and safety (roles, permissions, reports, bans, audit logs)
- Discovery and social graph (feeds, search, followers, recommendations)
- Monetization and business tooling (subscriptions, ads, analytics, CRM)
- Platform and ecosystem support (web/mobile/desktop sync, APIs, SDKs, integrations)

The goal is to support the broad feature set described in the issue statement, targeting parity-level capabilities inspired by major social and messaging platforms.

## Delivery approach

Given the scale, implementation should be delivered in phases:

1. Foundation: authentication, profile, direct/group messaging, notifications
2. Safety + privacy: encryption, moderation, permissions, account/device security
3. Media + realtime: calls, livestream, uploads, sync/offline, recommendations
4. Ecosystem + growth: payments, creators, APIs/SDKs, business/admin tooling
